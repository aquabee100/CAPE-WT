# Manuscript support

Compact derived tables for numerical claims in the paper.

- `warning_complementarity.csv` — channel episodes and provenance
- `warning_physical_dependence.csv` — correlations and co-fires
- `plugin_architecture.csv` — warning-to-confirmation convergence
- `kelmarsh_transfer_summary.csv` — external physical transfer
- `causality_summary.csv` — timing and future-invariance checks
- `detector_family_low_burden.csv` — 16 detector configurations
- `online_preprocessing_spec.csv` — exact online gates
